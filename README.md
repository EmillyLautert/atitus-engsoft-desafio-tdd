# 🧪 Laboratório de TDD: Desafios Progressivos

Exercícios de SRP, DIP e Clean Design em JavaScript com Jest. Cada nível possui uma suíte independente; entre na pasta correspondente, instale as dependências e execute `npm test`.

## Níveis

- **Nível 1 — SRP e persistência:** validadores especializados e serviço de cadastro com persistência atrás do contrato `UserRepository`.
- **Nível 2 — DIP:** serviço de notificação recebe um gateway por injeção de dependência; testes demonstram mocks e stubs.
- **Nível 3 — Clean Design:** refatoração da calculadora de voucher existente, guiada pelo ciclo Red-Green-Refactor, para os cupons `DEZ` e `TRINTA`.

Os READMEs de cada nível descrevem as regras, decisões e como executar os testes.
